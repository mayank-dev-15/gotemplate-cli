## About

**gotemplate-cli** is a professional go cli tool template.

### Key Features

- cobra command structure
- viper config management
- logrus structured logging
- Unit tests
- Shell completion
- Man page generation

---

## Tech Stack

- Go
- cobra
- viper
- logrus

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `--help` | Show usage |
| `--config` | Config file |
| `subcommands` | Various commands |
| `--version` | Show version |
